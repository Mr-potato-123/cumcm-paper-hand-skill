> AI Agent 写论文时参考这里的论文,学习结构、表达与图表方式(**只学不抄**)。

> OCR 版由自动识别生成,公式、上下标、图表可能有误差;需要精确公式/数据时对照原 PDF。

## 使用方式

1. **写论文前**:浏览与本题类型相近的 1–2 篇(如:本题是优化题 → 看 A196;B 题物理建模 → 看 B060/B157;C 题数据分析 → 看 C023/C132),学习其摘要写法、章节结构、图表设计与结果呈现。
2. **写作中**:遇到"这个部分怎么写"的问题,回到对应论文找范本。
3. **只学不抄**:学习思路与表达方式,不复制原文内容或公式。
4. **加自己的论文**:把你的参考论文也放进本目录(图片型 PDF 需生成可读版,见下)。

## 如何为图片型 PDF 生成可读版

本仓库的论文 PDF 为图片型(无文字层),已用 OCR 生成 `*.md`。如果你想添加自己的参考论文:

```bash
pip install rapidocr_onnxruntime pymupdf
python _tools/ocr_pdfs.py          # 在仓库根目录运行,自动处理 ref/ 下所有无 .md 的 PDF
```

输出为 `ref/<同名>.md`,即被 Agent 通读。
