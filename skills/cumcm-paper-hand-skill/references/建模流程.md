# 完整建模流程(仅用户明确要求重新建模/求解时执行)

由 [SKILL.md](../SKILL.md) Step 2 引用。默认不执行——已有建模/求解直接采用,本流程只在**用户明确要求重新建模/求解**时运行。

对每题执行闭环,并把每一步写进该题 `建模笔记.md`:

> 问题分析 → 模型建立 → 模型求解 → 结果分析 → 小结

## 1. 问题分析

题目要求 → 关键难点 → 数据/变量特征 → 总体建模思路 → 求解与检验方法。必须解释"为什么该模型适合本题"(选回归要说明变量间的相关趋势;选聚类要说明为何对样本分类;选优化要指出目标函数、决策变量、约束)。

## 2. 模型建立

先文字说明思路,再给公式,再逐项解释公式含义;优化问题给出标准型。

## 3. 模型求解

用 `问题X/代码/` 中已有代码或新写代码求解,记录关键参数与算法;结果写入 `结果/` 并注明来源文件。

## 4. 结果分析

结果趋势是否符合实际、误差是否合理、是否做敏感性/交叉验证/多模型对比等检验。

## 5. 小结

本问用了什么模型、求得什么结果、指标多少、给下一问留下什么输入。
