# 数学建模竞赛论文写作技能

面向 CUMCM / MCM/ICM 参赛者。在参赛者的参赛文件夹内按三步工作:**摸底 → 核对建模求解材料 → 写论文(LaTeX 交付)**。

> **本技能定位是「论文手」**:职责是基于参赛者**已有的建模笔记与求解结果**撰写论文。
> - 已有建模/求解 → **不得额外建模、不得重新求解**,直接采用,进入论文撰写;
> - 材料缺失需要补求解 → **必须先向参赛者确认**;补做后必须在交付说明中注明"本次新增求解:…";
> - 仅当用户明确要求重新建模/求解时,才执行完整建模流程。

## When to Use / When NOT to Use

**Use when**:用户要在参赛文件夹中建模、求解或撰写数模论文,或要求参考获奖论文(本技能 [ref/](ref/) 内置)学习论文写法。

**NOT use when**:
- 用户只需要算法概念解释或通用数学知识问答(不涉及参赛文件夹与论文产出);
- 用户明确指定使用其他建模 skill。

## 1. 参赛文件夹结构(工作前提)

参赛者应把**原始题目、每题的建模和解答**分文件夹整理好,结构见 [目录结构模板.md](templates/目录结构模板.md);未整理时按该模板补齐,或按现有文件归拢后继续。要点:

- `题目/`:原始题目与附件,**只读,不得修改**(问题重述必须来自这里);
- `问题X/建模笔记.md`:本题建模全过程,论文写作的第一手素材;
- `问题X/代码/`、`问题X/结果/`:可运行的求解代码与产物(图/表/数据)。

[论文模板](templates/) 与 [参考论文](ref/) 位于本技能目录内,与 SKILL.md 同级;找不到时直接问参赛者。

## 2. 工作流程

### Step 1 摸底(动笔前必须做)

1. 读取 `README.md` 与文件夹结构,列出全部题目、数据、已有笔记。
2. 读取 `题目/` 原始题目,逐问标注:研究对象、已知条件、核心矛盾、每问任务。
3. 检查每题 `建模笔记.md`;缺失的先补齐再继续。
4. 浏览 [ref/](ref/) 中与本题类型相近的 1–2 篇获奖论文(选篇逻辑见 [ref/README.md](ref/README.md))。

**出口标准**:题目逐问理解完毕,每题有建模笔记(或补齐方案),已选定参考论文。

### Step 2 核对建模与求解材料(不重复劳动)

本技能是论文手:**已存在的建模/求解,不得重新建模**。逐题检查:

1. **已有完整 `建模笔记.md` + `结果/`** → 直接采用,不重新建模、不重新求解,进入 Step 3。
2. **有代码与结果、但笔记缺失或不完整** → 基于代码与结果补齐笔记(只记录已有事实,不新增建模),进入 Step 3。
3. **有笔记、无求解结果** → 向参赛者确认是否需要补求解;**补求解前必须先说明,补完后在交付说明中注明"本次新增求解:…"**。
4. 仅当**用户明确要求**重新建模/求解时,才执行完整建模流程,并把每一步写进建模笔记:

> 问题分析 → 模型建立 → 模型求解 → 结果分析 → 小结

- **问题分析**:题目要求 → 关键难点 → 数据/变量特征 → 总体建模思路 → 求解与检验方法。必须解释"为什么该模型适合本题"(选回归要说明变量间的相关趋势;选聚类要说明为何对样本分类;选优化要指出目标函数、决策变量、约束)。
- **模型建立**:先文字说明思路,再给公式,再逐项解释公式含义;优化问题给出标准型。
- **模型求解**:用 `问题X/代码/` 中已有代码或新写代码求解,记录关键参数与算法;结果写入 `结果/` 并注明来源文件。
- **结果分析**:结果趋势是否符合实际、误差是否合理、是否做敏感性/交叉验证/多模型对比等检验。
- **小结**:本问用了什么模型、求得什么结果、指标多少、给下一问留下什么输入。

**出口标准**:每题材料核对完毕(采用已有或经确认后补齐),未做任何未经说明的建模/求解;下一问的输入已明确。

### Step 3 撰写论文(LaTeX 交付)

1. 通读全部建模笔记与结果,先梳理**叙事逻辑**:问题二是否使用问题一的模型?问题三是在问题一基础上扩展还是新模型?前一问的输出是否成为后一问的输入?后一问能否验证前一问的合理性?——先梳理再动笔。
2. **完整读取 [数模.md](数模.md)(论文写作规范主干),并逐条执行其中的写作要求**。
3. 读取 [论文模板.tex](templates/论文模板.tex),在其骨架上写作,输出到 `论文/论文.tex`。骨架固定为:

```
摘要 → 问题重述 → 问题分析 → 模型假设 → 符号说明 → 模型建立与求解 → 模型评价与推广 → 参考文献 → 附录
```

4. **摘要最后写**(正文定稿后写),每问句式:针对…问题,首先…,随后建立…模型,采用…算法求解,得到…结果;通过…检验,表明模型…。直接写数值与指标,禁止"结果良好、具有一定可行性"之类空话。
5. 每问末尾加小结:"综上,本文建立了…模型,求得…,模型在验证集上的指标为…,说明模型…,所得结果将在问题X作为…使用"。
6. 图表:图/表编号+标题,三线表(booktabs),对比表中最优值加粗 `\textbf{}`,每张图表必须在正文中被引用与讨论("看图说话")。
7. 用 XeLaTeX 编译 `论文.tex` 两次(处理交叉引用),产出 `论文.pdf`;编译报错必须修复到零错误。
8. 若参赛者已提供 `论文/` 下草稿,在草稿基础上修改,不推倒重来。
9. 对照第 6 节检查清单逐项核对,把核对结果汇报给参赛者。

**出口标准**:`论文.tex` 编译零错误,`论文.pdf` 交付,检查清单全部通过或已知偏差已说明。

## 3. 写作规范(以 数模.md 为准)

写作规范主干是 [数模.md](数模.md),**写论文前必须完整读取并逐条执行**。核心要点速查(全部要求以 数模.md 为准):

- 每问闭环:问题分析 → 模型建立 → 模型求解 → 结果分析 → 小结;子问题间必须有承接过渡。
- 问题重述:用自己的话逐问叙事,不照抄题目;把小问整理为明确数学任务。
- 问题分析:题目要求 → 关键难点 → 数据特征 → 建模思路 → 检验方法;解释模型适用性。
- 模型假设 5–10 条且每条有理由;符号用三线表且全文统一。
- 公式三段式:先文字 → 公式 → 逐项解释;优化问题给标准型;不写"调用了 xxx 函数"。
- 算法:伪代码或有效流程图(体现初始化、迭代、约束判断、终止条件)。
- 数据预处理交代五要素(什么问题/什么方法/关键参数/为何选/保留什么特征)。
- 结果可信:误差/残差/交叉验证/敏感性/多模型对比,正文直接回答题目。
- 参考文献:WebSearch 逐一核实,8–15 篇高质量文献,禁止编造;附录与正文严格对应,不凑数。

## 4. ref/ 获奖论文使用规则

选篇逻辑与逐篇学习点见 [ref/README.md](ref/README.md)。使用规则:

- [ref/*.md](ref/) 为 OCR 可读版(公式/上下标可能有误差),原 [ref/*.pdf](ref/) 为准。
- 写论文前浏览与本题类型相近的 1–2 篇,学其摘要写法、章节结构、图表设计、结果呈现。
- **只学不抄**:学习结构与表达方式,禁止复制原文内容或公式;借鉴思路须结合本题重新表述。
- 需要精确公式/数据时对照原 PDF 或询问参赛者。

## 5. 硬性约束

1. **不编造**:论文中每个数值必须能追溯到 `结果/` 或 `代码/` 中的某个文件;找不到来源的结果禁止写入论文。
2. **不重复劳动**:已存在的建模/求解直接采用,不得额外建模;补求解必须先确认并作出说明。
3. **文献必须真实**:参考文献用 WebSearch 逐一搜索核实(作者、题名、期刊、年份、卷期页码),禁止凭记忆编造;数量建议 8–15 篇,优先期刊论文、学位论文、权威专著,与正文内容强相关,禁止无关文献凑数。
4. **附录不糊弄**:附录内容(推导、核心代码、大表格)必须与正文严格对应、真实可查,每条编号与正文标注一致;不放无关内容凑页数。
5. **不清楚就问**:建模笔记缺失、结果对不上、附件打不开时,先问参赛者,不擅自假设。
6. **先草稿后终稿**:先出 Markdown 草稿供确认,再落 LaTeX 终稿与 PDF。
7. **语言**:国赛中文;美赛中文稿定稿后译英文,并检查英文表达。

## 6. 交付检查清单(写完逐项核对)

- [ ] 骨架完整:摘要 → 问题重述 → 问题分析 → 模型假设 → 符号说明 → 模型建立与求解 → 模型评价与推广 → 参考文献 → 附录
- [ ] 每问闭环,子问题有承接过渡
- [ ] 摘要最后写,每问有具体数值与指标,无空话
- [ ] 问题重述用自己话;问题分析解释了模型适用性
- [ ] 假设 5–10 条且有理由;符号三线表且全文统一
- [ ] 公式有引导文字、逐项解释;优化问题有标准型
- [ ] 每张图表有编号标题、正文被引用讨论、对比表最优值加粗
- [ ] 数据预处理五要素齐全;结果有检验;正文直接回答题目
- [ ] 参考文献逐一搜索核实过(真实存在),数量 8–15 篇且与正文强相关,格式统一、正文有标注
- [ ] 附录与正文标注一一对应,内容真实对应(推导一致、代码可运行、表格同源),无凑数
- [ ] 未做任何未经说明的建模/求解(论文手定位);补求解已注明"本次新增求解:…"
- [ ] `论文.tex` 用 XeLaTeX 编译零错误,交付 `论文.pdf`
