# 数学建模竞赛论文写作技能

在参赛文件夹内三步工作:**摸底 → 核对材料 → 写论文(LaTeX 交付)**。

## When to Use / When NOT to Use

- **Use when**:用户要在参赛文件夹中建模、求解或撰写数模论文,或要求参考获奖论文([ref/](ref/) 内置)学习论文写法。
- **NOT use when**:用户只需要算法概念解释或通用数学知识问答;用户明确指定使用其他建模 skill。

## 输入:参赛文件夹结构

参赛者把**原始题目、每题的建模和解答**分文件夹整理,结构见 [templates/目录结构模板.md](templates/目录结构模板.md);未整理时按该模板补齐或按现有文件归拢。要点:

- `题目/`:原始题目与附件,**只读,不得修改**;
- `问题X/建模笔记.md` + `代码/` + `结果/`:本题建模过程与产物,论文素材来源;
- `论文/`:输出 `论文.tex`、`论文.pdf`、附图。

## 工作流程

### Step 1 摸底

1. 读取 `README.md` 与文件夹结构,列出全部题目、数据、已有笔记。
2. 读取 `题目/` 原始题目,逐问标注:研究对象、已知条件、核心矛盾、每问任务。
3. 检查每题 `建模笔记.md`,缺失的先补齐。
4. 浏览 [ref/README.md](ref/README.md),选定与本题类型相近的 1–2 篇参考论文。

**出口标准**:题目逐问理解完毕,每题有笔记或补齐方案,参考论文已选定。

### Step 2 核对建模与求解材料

**已存在的建模/求解,不得重新建模或重新求解**——直接采用。逐题检查:

1. 有完整 `建模笔记.md` + `结果/` → 直接采用,进 Step 3。
2. 有代码与结果、笔记缺失 → 只补齐笔记(记录已有事实),进 Step 3。
3. 有笔记、无结果 → 向参赛者确认是否补求解;补完在交付说明注明"本次新增求解:…"。
4. 仅当**用户明确要求**重新建模/求解时,执行 [references/建模流程.md](references/建模流程.md) 的完整闭环。

**出口标准**:未做任何未经说明的建模/求解;下一问输入已明确。

### Step 3 撰写论文(LaTeX 交付)

1. 通读全部笔记与结果,先梳理**叙事逻辑**:问题二是否使用问题一的模型?问题三是在问题一基础上扩展还是新模型?前一问输出是否成为后一问输入?后一问能否验证前一问合理性?——先梳理再动笔。
2. **完整读取 [references/论文写作规范.md](references/论文写作规范.md) 并逐条执行**——骨架、每问闭环、摘要句式、图表、文献、附录等全部写作要求都在其中。
3. 以 [templates/论文模板.tex](templates/论文模板.tex) 为骨架写 `论文/论文.tex`,骨架固定为:

```
摘要 → 问题重述 → 问题分析 → 模型假设 → 符号说明 → 模型建立与求解 → 模型评价与推广 → 参考文献 → 附录
```

4. XeLaTeX 编译 `论文.tex` 两次(处理交叉引用),产出 `论文.pdf`,报错修复到零错误。
5. 已有草稿则修改完善,不推倒重来。
6. 对照 [references/检查清单.md](references/检查清单.md) 逐项核对,结果汇报给参赛者。

**出口标准**:`论文.tex` 编译零错误,`论文.pdf` 交付,检查清单全部通过或已知偏差已说明。

## 硬性约束(每次遵守)

1. **不编造**:论文中每个数值必须能追溯到 `结果/` 或 `代码/` 中的文件;找不到来源的结果禁止写入论文。
2. **不重复劳动**:已存在的建模/求解直接采用;补求解必须先确认并说明。
3. **文献必须真实**(细则见 [references/论文写作规范.md](references/论文写作规范.md) 第 8 节):WebSearch 逐一核实,禁止编造。
4. **附录不糊弄**(细则见 [references/论文写作规范.md](references/论文写作规范.md) 第 9 节):与正文严格对应,不凑数。
5. **不清楚就问**:材料缺失、结果对不上时先问参赛者,不擅自假设。
6. **先草稿后终稿**:先出 Markdown 草稿供确认,再落 LaTeX 终稿与 PDF。
7. **语言**:国赛中文;美赛中文稿定稿后译英文。
