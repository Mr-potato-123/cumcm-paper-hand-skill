# templates/ —— 模板说明

| 文件 | 用途 |
|------|------|
| `论文模板.tex` | **论文唯一模板**(XeLaTeX 编译)。含国赛页面设置、三线表(booktabs)、公式环境、算法环境、附录。最终论文交付为 `论文.tex` + 编译后的 `论文.pdf` |
| `论文模板.pdf` | 模板编译预览(108KB),没装 TeX 也能看效果;不是交付物 |
| `建模笔记模板.md` | 每道题的建模笔记模板。建模时随手记,是 AI 写论文的第一手素材 |
| `目录结构模板.md` | 参赛文件夹目录结构模板。复制即用,一次参赛一个文件夹 |

## 使用方式

1. **参赛准备**:按 `目录结构模板.md` 建好参赛文件夹,题目、每题建模笔记、代码、结果分文件夹放好。
2. **每题建模**:用 `建模笔记模板.md` 写 `问题X/建模笔记.md`。
3. **写论文**:AI Agent 以 `论文模板.tex` 为骨架写 `论文/论文.tex`,XeLaTeX 编译两次产出 PDF。论文只以 LaTeX 形式交付。
