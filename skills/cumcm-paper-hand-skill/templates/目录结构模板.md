# 参赛文件夹目录结构模板

> 一次参赛 = 一个文件夹。把**原始题目、每道题的建模和解答**分文件夹整理好,AI Agent 就能在这个文件夹里完成全部工作。
> 使用方法:复制下面的结构,把 `my-mcm-project` 改成你的项目名。

```
my-mcm-project/
├── README.md                        # 项目说明:题目清单、小组成员、进度
├── 题目/                            # ★ 原始题目与数据(只读,不修改)
│   ├── 2024A_题目.pdf               # 原始题目原文
│   └── 附件/
│       ├── data1.xlsx
│       └── ...
├── 问题A/                           # ★ 每个题目一个文件夹
│   ├── 建模笔记.md                  # 本题建模思路与模型(用 templates/建模笔记模板.md)
│   ├── 代码/
│   │   ├── main.py                  # 本题求解代码
│   │   └── README.md                # 代码说明:依赖、运行方式
│   ├── 结果/
│   │   ├── 图1_数据分布.png
│   │   ├── 图2_模型对比.png
│   │   └── result.csv
│   └── 解答.md                      # 本题完整解答草稿(论文章节素材)
├── 问题B/
│   ├── 建模笔记.md
│   ├── 代码/
│   ├── 结果/
│   └── 解答.md
├── 问题C/
│   └── ...
├── 论文/                            # 最终论文
│   ├── 论文.md                      # 论文草稿/终稿(用 templates/论文模板.md)
│   ├── 附图/                        # 论文用图(高清/矢量)
│   └── 论文.docx                    # 最终提交版本
└── 参考资料/
    ├── 文献1.pdf                    # 自己找的参考文献
    └── 获奖论文.pdf
```

## 使用说明

| 文件夹 | 作用 | 谁维护 |
|--------|------|--------|
| `题目/` | 题目原文与附件,**不修改** | 队长(第一天放好) |
| `问题X/建模笔记.md` | 建模全过程记录,论文的第一手素材 | 建模手(AI 协助) |
| `问题X/代码/` | 可运行的求解代码,结果可复现 | 编程手(AI 协助) |
| `问题X/结果/` | 图表与数据,论文用图从这取 | 编程手 |
| `问题X/解答.md` | 本题完整解答,汇总成论文 | 建模手 |
| `论文/` | 论文草稿→终稿 | 论文手(AI 协助) |

## 不整理也能做的说明

如果参赛者没有按此结构整理,AI Agent 会先**询问/扫描**现有文件,按上面的逻辑重新归拢(只创建链接或整理后的笔记,不移动你的原始文件),效果略打折但可工作。
