# ref/ —— 获奖优秀论文参考库(选篇说明)

> AI Agent 写论文前浏览与本题类型相近的 1–2 篇,学结构、表达与图表方式(**只学不抄**)。
> 每篇提供 **原 PDF**(权威版本)与 **OCR 可读版 `*.md`**(供 Agent 通读;公式、上下标可能有误差,精确信息以 PDF 为准)。

## 选篇逻辑:特意覆盖三种题型

这套论文不是随手收集的,而是**按国赛三大题型刻意选取**,保证参赛者无论做哪一类题,都能在库里找到对口的范本:

| 题型 | 对应论文 | 覆盖情况 |
|------|---------|---------|
| **A 题 · 优化类**(运筹/调度/策略) | A196 | 1 篇,完整的多问递进优化案例 |
| **B 题 · 物理建模类**(机理/测量/工程) | B060、B157 | 2 篇,**同一道题的两种不同建模路线** |
| **C 题 · 数据分析类**(统计/机器学习/决策) | C023、C132 | 2 篇,**同一道题的两种不同方法路线** |

### 三组对照怎么用

- **A 题方向**:看 A196 怎么把一道多情形优化题拆成五个递进子问题,以及分层次优化/降维的思路。
- **B、C 同题双篇**:B060 与 B157 都是"外延层厚度测量"、C023 与 C132 都是"NIPT 检测",但**建模路线截然不同**——这正是最值得学的:同一份题目、同一份数据,可以走出不同的建模道路。写论文不确定选哪条路时,对照两篇看各自用什么模型、什么检验、什么创新点,取适合本题的一条。
- **跨题型通用**:不管做哪类题,每篇的**摘要句式、章节结构、图表设计、模型评价**写法都是通用的,写作卡壳时回来翻对应篇目。
