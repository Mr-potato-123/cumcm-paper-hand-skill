# templates/ —— 模板说明

本目录为参赛者提供可复用的模板,AI Agent 写论文前应读取 `论文模板.md`。

| 文件 | 用途 |
|------|------|
| `论文模板.md` | 论文写作模板(Markdown)。按骨架组织,每节附写作要点,直接填空即可成稿 |
| `论文模板.tex` | 论文 LaTeX 模板(XeLaTeX 编译)。含国赛页面设置、三线表、公式环境、算法环境、附录 |
| `建模笔记模板.md` | 每道题的建模笔记模板。建模时随手记,是 AI 写论文的第一手素材 |
| `目录结构模板.md` | 参赛文件夹目录结构模板。复制即用,一次参赛一个文件夹 |

## 使用方式

1. **参赛准备**:把 `目录结构模板.md` 中的结构建到你的参赛文件夹。
2. **每题建模**:用 `建模笔记模板.md` 写 `问题X/建模笔记.md`,边建模边记。
3. **写论文**:AI Agent 读取 `论文模板.md`,结合建模笔记与代码结果写作;需要 LaTeX 版时用 `论文模板.tex`。
